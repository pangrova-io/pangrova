# DOUBLE


| Property | Value |
|----------|-------|
| Storage | 64-bit IEEE 754 floating point |
| Precision | ~15 decimal digits |
| Alias | `DOUBLE PRECISION` |

```sql
CREATE TABLE coordinates (id BIGINT, latitude DOUBLE, longitude DOUBLE PRECISION);
```
