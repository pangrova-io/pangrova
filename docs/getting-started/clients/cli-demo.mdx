## Workflow at a glance

1. Register a local Apache Iceberg catalog.
2. Create an analytics schema and a partitioned events table.
3. Inspect the table with `DESCRIBE`.
4. Insert six rows in one statement.
5. Query the detail rows and aggregate them by region and event type.

## Replay the example

The equivalent SQL workflow is available in
[`examples/cli-workflow.sql`](https://github.com/pangrova-io/pangrova/blob/2d8efa28545e033e6bac68c5904048d3ae513a24/examples/cli-workflow.sql)
with a different local warehouse path than the recording. Follow the
[Standalone quickstart](../quickstart.md) to prepare and start the local
Coordinator and Worker. Run the following from the repository root only against
a fresh, isolated development instance with permission to create catalogs,
schemas, and tables. Ensure that `demo_iceberg.analytics.events` and
`/tmp/pangrova-cli-warehouse` are unused before starting.

```bash
bin/pangrova-cli.sh --host localhost --port 8080 < examples/cli-workflow.sql
```

Piped input runs the interactive shell and continues after statement errors.
Verify that all eight SQL statements succeed, that the detail query returns six
rows, that region counts are `east=2`, `north=1`, `south=1`, `west=2`, and that
event-type counts are `click=3`, `purchase=2`, `search=1`. A zero exit code from
the interactive shell alone does not establish successful execution.

For fail-fast automation, execute the eight statements in order using eight
separate single-statement UTF-8 files and `--file` for each invocation, stopping
on the first nonzero exit. The example is a multi-statement file and must not be
passed directly to `--file`. See [the CLI reference](./cli.md#script-mode) for
script-mode output and execution receipts.

## Optional cleanup

After verifying the results, you can remove the table and unregister the
example catalog. Run these statements only if they refer to the objects created
by this demo, not shared or production data. They are intentionally separate
from the replay file.

```sql
DROP TABLE demo_iceberg.analytics.events;
DROP CATALOG demo_iceberg;
```
