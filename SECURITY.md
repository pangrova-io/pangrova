# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅ Security updates |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public issues.**

Send an email to [security@pangrova-project.org] with:

1. Vulnerability description
2. Steps to reproduce
3. Impact assessment
4. Possible fix (if any)

We will acknowledge receipt within 48 hours and provide an initial assessment within 7 days.

## Disclosure Policy

- After confirming the vulnerability, we will coordinate a fix timeline with the reporter
- After the fix is released, we will publicly credit the reporter (unless they prefer anonymity)
- We follow a 90-day disclosure deadline

## Security Best Practices

When using Pangrova:

1. Always use the latest stable version
2. Enable authentication and authorization
3. Use TLS for encrypted communication
4. Regularly audit access logs
5. Follow the principle of least privilege
